# Proposal: 康 Core 進階功能九連發

## 動機

核心功能（記帳/收納/行事曆/認證/CRUD/圖表/匯出）已完成。
為了讓系統從「能用的工具」升級為「離不開的個人管家」，需要加入主動智慧、對話查詢、快速操作等進階能力。

## 範圍

共 9 個功能模組，分為 3 個優先級批次：

### Batch A — 高優先（被動→主動的質變）

| # | 功能 | 核心價值 |
| :--- | :--- | :--- |
| 1 | 定期/固定支出 | 房租、訂閱自動入帳，區分固定 vs 變動 |
| 2 | LINE 主動推播 | 每日消費摘要、行事曆提醒、月報 |
| 3 | 對話式查詢 | 在 LINE 裡直接問「本月吃飯花多少」 |

### Batch B — 中優先（體驗升級）

| # | 功能 | 核心價值 |
| :--- | :--- | :--- |
| 4 | 自訂標籤/子分類 | 更細顆粒度的消費分析 |
| 5 | PWA 安裝 | 手機桌面直接開，像原生 App |
| 6 | 深色/淺色模式切換 | 不同環境更好閱讀 |

### Batch C — 進階（差異化亮點）

| # | 功能 | 核心價值 |
| :--- | :--- | :--- |
| 7 | AI 消費洞察 | Gemini 分析消費模式，給出建議 |
| 8 | 快速記帳指令 | `/記 150 午餐` 不走 AI，秒入帳 |
| 9 | 收據自動分類規則 | 記住商家→標籤對應，下次自動套用 |

## 非範圍

- 不做多用戶管理
- 不做銀行帳戶對接（台灣 Open Banking 尚未成熟）
- 不做即時匯率換算
