# Kang Bot 使用說明

個人 AI 生活助理，透過 LINE 用自然語言記帳、查詢、儲存知識。

---

## 加入方式

掃描 Bot QR Code，加好友即可使用。**每位用戶的資料完全獨立隔離。**

---

## 功能一覽

### 💰 記帳

不需要特定格式，直接用中文描述即可。AI 會自動判斷金額、分類。

| 輸入方式 | 範例 |
|---------|------|
| 自然語言 | `早餐花了80` |
| 多筆一次記 | `午餐120，下午茶55，晚餐250` |
| 含日期 | `昨天買衣服花了1200` |
| 指令格式 | `/記 150 午餐` |
| 拍照記帳 | 直接傳收據或發票圖片，AI 自動辨識 |

**支援分類：** 餐飲、交通、娛樂、水電、購物、醫療、教育、保險、收入、其他

---

### 🔍 查詢消費

| 指令 | 說明 |
|------|------|
| `/查 本月` | 本月消費統計 + 各類別金額 |
| `/查 上月` | 上個月統計 |
| `/查 本週` | 本週統計 |
| `/查 上週` | 上週統計 |
| `/查 今天` | 今日消費 |

---

### 📊 預算管理

| 指令 | 說明 |
|------|------|
| `/預算` | 查看本月預算使用狀況 |
| `/預算 設定 5000` | 設定月預算為 $5,000 |

超過 80%、100% 時 Bot 會自動推播提醒。

---

### 🧠 AI 消費洞察

輸入 `/洞察`，AI 會分析你的消費習慣並給出具體建議。

---

### 📌 待辦事項 / 行事曆

| 輸入方式 | 範例 |
|---------|------|
| 自然語言 | `明天下午3點牙醫` |
| 快速指令 | `/待 繳電費` |
| 完成待辦 | `/完成 繳電費` |

待辦事項會自動同步到 Google Calendar。

---

### 📁 知識庫（存檔）

任何你想記住的東西，直接傳給 Bot 就會儲存起來，之後可以用自然語言查詢。

| 可儲存的內容 | 說明 |
|------------|------|
| 文字筆記 | 直接輸入想記的文字 |
| 網址 | 傳入 URL，AI 自動摘要並分類 |
| 圖片 | AI 辨識內容後儲存 |
| 檔案（PDF 等）| AI 解析內容存入知識庫 |

**查詢知識庫：**

```
/問 上次記的那個醫院電話是多少？
```

---

### 📂 查看最近上傳的檔案

```
/recent_files
```

列出最近 5 筆上傳到 Google Drive 的檔案。

---

### 💬 一般對話

不需要指令，直接說話。Bot 有短期記憶（15 分鐘），可以追問或繼續對話。

```
你：這個月吃最多什麼？
Bot：根據你的記錄，餐飲 $3,200，其中外食占最多...
```

---

## 所有快速指令

輸入 `/help` 可在 LINE 中隨時查看。

| 指令 | 功能 |
|------|------|
| `/記 {金額} {描述}` | 快速記帳 |
| `/查 {時間}` | 查詢消費統計 |
| `/待 {標題}` | 建立待辦 |
| `/完成 {關鍵字}` | 標記待辦完成 |
| `/預算` | 查看預算 |
| `/預算 設定 {金額}` | 設定月預算 |
| `/洞察` | AI 消費分析 |
| `/問 {問題}` | 查詢知識庫 |
| `/recent_files` | 最近上傳的檔案 |
| `/help` | 顯示指令說明 |

---

## 注意事項

- **資料隔離**：每位用戶的記帳、知識庫、分類規則都是獨立的，互不干擾。
- **AI 學習**：Bot 會記住你的消費習慣，同樣的商家下次輸入時會自動套用分類。
- **對話記憶**：短期記憶 15 分鐘，關閉對話視窗後重新開啟記憶會清除。
